# اجرای نمونه JavaScript

این نمونه قیمت‌های طلا، ارز و کریپتو را از نسخه ۲ API دریافت و در کنسول نمایش می‌دهد.

## پیش‌نیازها

- Node.js 18 یا جدیدتر (برای `fetch` داخلی)

## مراحل اجرا

1. توکن خود را در فایل `index.js` جایگزین کنید:

```javascript
API_TOKEN: process.env.NERKH_API_TOKEN || "YOUR_TOKEN_HERE"
```

یا بدون تغییر فایل، توکن را به‌صورت متغیر محیطی بدهید:

```bash
NERKH_API_TOKEN="YOUR_TOKEN_HERE" node index.js
```

2. وارد پوشه پروژه شوید:

```bash
cd examples/javascript
```

3. کد را اجرا کنید:

```bash
node index.js
```

یا:

```bash
npm start
```

## خروجی مورد انتظار

فهرست آیتم‌ها به‌صورت گروه‌بندی‌شده (طلا، ارز و کریپتو) همراه با قیمت، درصد تغییر ۲۴ ساعته و زمان به‌روزرسانی چاپ می‌شود.

```text
=== طلا (22 آیتم) ===
نماد                          قیمت   تغییر ۲۴س  به‌روزرسانی
GOLD18K                  25972500      1.96%  1405-08-13 15:40:48
...

مجموع: 43 آیتم
```

## خطاهای رایج

- **HTTP 401**: توکن اشتباه یا نامعتبر است.
- **HTTP 403**: توکن غیرفعال (deactivated) شده است.
- **HTTP 460**: تعداد درخواست‌ها بیش از حد مجاز است (QuotaExceeded)؛ سهمیه را از `cp.nerkh.io` مدیریت کنید.
- **HTTP 404**: مسیر یا نسخه API اشتباه است.
- **node not found**: Node.js نصب نیست.
- **fetch is not defined**: نسخه Node.js قدیمی است؛ از 18 یا جدیدتر استفاده کنید.

# اجرای نمونه Vue

این نمونه با Vite اجرا می‌شود و قیمت‌های طلا، ارز و کریپتو را از نسخه ۲ API نمایش می‌دهد.

## پیش‌نیازها

- Node.js 18 یا جدیدتر
- npm

## مراحل اجرا

1. توکن خود را در فایل `src/App.vue` جایگزین کنید:

```javascript
API_TOKEN: "YOUR_TOKEN_HERE"
```

2. وارد پوشه پروژه شوید و وابستگی‌ها را نصب کنید.

### لینوکس / مک

```bash
cd examples/vue
npm install
npm run dev
```

### ویندوز (PowerShell)

```powershell
cd examples\vue
npm install
npm run dev
```

### ویندوز (CMD)

```bat
cd examples\vue
npm install
npm run dev
```

3. در مرورگر به آدرس زیر بروید:

```text
http://localhost:5173
```

## خروجی مورد انتظار

کارت‌های قیمت به‌صورت گروه‌بندی‌شده (طلا، ارز و کریپتو) همراه با قیمت، درصد تغییر ۲۴ ساعته و زمان به‌روزرسانی نمایش داده می‌شوند.

## نکات امنیتی

- در پروژه واقعی توکن را داخل کد فرانت‌اند قرار ندهید.
- از یک بک‌اند واسط (مثل نمونه `examples/nodejs`) استفاده کنید.

## خطاهای رایج

- **HTTP 401**: توکن اشتباه یا نامعتبر است.
- **HTTP 403**: توکن غیرفعال (deactivated) شده است.
- **HTTP 460**: تعداد درخواست‌ها بیش از حد مجاز است (QuotaExceeded)؛ سهمیه را از `cp.nerkh.io` مدیریت کنید.
- **HTTP 404**: مسیر یا نسخه API اشتباه است.
- **npm not found**: Node.js و npm نصب نیستند.
- **Failed to fetch**: اتصال اینترنت یا CORS مشکل دارد.

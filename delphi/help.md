# اجرای نمونه Delphi

این نمونه قیمت‌های طلا، ارز و کریپتو را از نسخه ۲ API دریافت و در کنسول نمایش می‌دهد.

## پیش‌نیازها

- Delphi 10.3 یا جدیدتر (برای `System.Net.HttpClient` و `System.JSON`)
- فایل سورس با کدگذاری UTF-8 (ترجیحاً UTF-8 with BOM) ذخیره شود

## مراحل اجرا

1. توکن خود را در فایل `NerkhExample.dpr` جایگزین کنید:

```pascal
API_TOKEN = 'YOUR_TOKEN_HERE';
```

2. پروژه را در Delphi باز کنید و به‌صورت Console Application اجرا کنید، یا از خط فرمان استفاده کنید:

```bash
cd examples/delphi
dcc32 NerkhExample.dpr
NerkhExample.exe
```

## خروجی مورد انتظار

فهرست آیتم‌ها به‌صورت گروه‌بندی‌شده (طلا، ارز و کریپتو) همراه با قیمت، درصد تغییر ۲۴ ساعته و زمان به‌روزرسانی چاپ می‌شود.

```text
=== طلا (22 آیتم) ===
نماد                          قیمت   تغییر ۲۴س  به‌روزرسانی
GOLD18K                  25972500      1.96%  1405-08-13 15:40:48
...

مجموع: 43 آیتم
```

## خطاهای رایج

- **HTTP 401**: توکن اشتباه یا نامعتبر است.
- **HTTP 403**: توکن غیرفعال (deactivated) شده است.
- **HTTP 460**: تعداد درخواست‌ها بیش از حد مجاز است (QuotaExceeded)؛ سهمیه را از `cp.nerkh.io` مدیریت کنید.
- **HTTP 404**: مسیر یا نسخه API اشتباه است.
- **dcc32 not found**: مسیر کامپایلر Delphi در `PATH` نیست.
- **E2003 Undeclared identifier 'THTTPClient'**: نسخه Delphi قدیمی است.
- **به‌هم‌ریختگی متن فارسی**: فایل را با UTF-8 ذخیره و خروجی کنسول را روی UTF-8 تنظیم کنید.

# اجرای نمونه HTML

این نمونه قیمت‌های طلا، ارز و کریپتو را از نسخه ۲ API دریافت و در مرورگر نمایش می‌دهد.

## مراحل اجرا

1. توکن خود را در فایل `index.html` جایگزین کنید:

```javascript
API_TOKEN: "YOUR_TOKEN_HERE"
```

2. فایل را مستقیماً در مرورگر باز کنید، یا یک سرور محلی اجرا کنید:

```bash
cd examples/html
python3 -m http.server 8000
```

سپس در مرورگر به آدرس زیر بروید:

```text
http://localhost:8000
```

## خروجی مورد انتظار

کارت‌های قیمت به‌صورت گروه‌بندی‌شده (طلا، ارز و کریپتو) همراه با قیمت، درصد تغییر ۲۴ ساعته و زمان به‌روزرسانی نمایش داده می‌شوند.

## نکات امنیتی

- توکن را در پروژه واقعی داخل کد سمت مرورگر قرار ندهید.
- برای استفاده واقعی، درخواست را از سرور خود ارسال کنید تا توکن افشا نشود.
- قبل از انتشار در گیت‌هاب، مقدار توکن را به `YOUR_TOKEN_HERE` برگردانید.

## خطاهای رایج

- **HTTP 401**: توکن اشتباه یا نامعتبر است.
- **HTTP 403**: توکن غیرفعال (deactivated) شده است.
- **HTTP 460**: تعداد درخواست‌ها بیش از حد مجاز است (QuotaExceeded)؛ سهمیه را از `cp.nerkh.io` مدیریت کنید.
- **HTTP 404**: مسیر یا نسخه API اشتباه است.
- **Failed to fetch**: اتصال اینترنت یا دسترسی CORS مشکل دارد.
